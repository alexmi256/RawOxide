# Fixtures

Committed, deterministic artefacts generated by the Python reference. They let
the Rust test suite run without Python, NumPy, Pillow, tifffile or network
access.

Regenerate (requires the Python venv in `../../RawHide/.venv`):

```bash
python3 scripts/gen_fixtures.py --force
# or: just fixtures
```

Review the diff before committing. `manifest.json` records sizes and SHA-256
hashes; `golden/environment.json` records the oracle versions.

## Contents

| path | purpose |
|---|---|
| `payloads/*.bin` | deterministic plaintext payloads used by the DNG fixtures |
| `dng/linear_256x192_16bit_1plane.dng` | default path, 16-bit linear, 1 plane |
| `dng/linear_128x96_8bit_deflate.dng` | 8-bit linear, Adobe Deflate |
| `dng/cfa_128x96_14bit_2planes.dng` | packed 14-bit CFA, 2 planes |
| `dng/linear_128x96_16bit_4planes_keyed.dng` | keyed payload, 4 planes |
| `dng/linear_128x96_16bit_3frames.dng` | three raw SubIFDs |
| `dng/split0001.dng`, `split0002.dng` | split set with shared UUID |
| `golden/framing.json` | Python framing + keystream vectors |
| `golden/codec.json` | Python LSB embed mapping (cover before/after) |
| `golden/capacity.json` | Python capacity/formatting vectors |
| `golden/environment.json` | oracle versions used to generate the set |

## Rules

- Do not hand-edit a DNG or payload.
- Do not add large fixtures; keep the set under a few MiB.
- If the Python oracle changes output in a way that is intentional, regenerate
  with `--force` and call it out in the PR.
- The Python project's `.gitignore` ignores `*.dng`; this directory is outside
  that project and is tracked explicitly by Git.
